# Crazy Block

A bilingual Tetris game built with Phaser 3, Vite, and TypeScript.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Controls

- Mouse left click: move left
- Mouse right click: move right
- Mouse left hold: fast drop
- Mouse wheel up: rotate clockwise
- Mouse wheel down: rotate counter-clockwise
- Keyboard A/D: move left/right
- Keyboard W: rotate clockwise
- Keyboard S tap: rotate counter-clockwise
- Keyboard S hold: fast drop
- Keyboard P/Esc: pause
